Connect or reconnect AnyFix Books

AnyFix Books is a private integration. It runs locally on a computer controlled by AnyFix Systems LLC and has no hosted web application, so connecting is done from a terminal rather than from a web page.

To connect, or to reconnect after a disconnect

Run the authorization command:

~/anyfix-books/qbo-mcp/.venv/bin/qbo-auth

It asks for the Intuit app's client ID, client secret, environment and redirect URI, then opens the QuickBooks consent screen in a browser. Approving the consent screen returns an authorization code, which the tool exchanges for tokens and stores in the macOS Keychain. Nothing is written to disk in plain text.

Confirming the connection

After authorizing, the company file that is connected can be confirmed by running the integration's qbo_company_info operation. It reports the company name and whether the sandbox or production environment is live. This should be checked before any records are written.

When a reconnect is needed

  • The refresh token has expired. Intuit expires a refresh token after 100 days without use; the integration reports invalid_grant when this has happened.
  • Access was revoked from the QuickBooks Online account.
  • The integration is being pointed at a different company file or a different environment.
