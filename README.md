# AnyFix Systems LLC — legal pages

Public-facing legal documents for **AnyFix Books**, a private QuickBooks Online
integration used by AnyFix Systems LLC for its own bookkeeping.

These pages exist because Intuit requires a publicly reachable end-user license
agreement and privacy policy URL before it will issue production API credentials.

Served via GitHub Pages:

- `/privacy/` — Privacy Policy
- `/eula/` — End-User License Agreement

Source for both documents lives alongside the rendered HTML; edit the document,
re-render, and push.
