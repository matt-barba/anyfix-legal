AnyFix Books — Privacy Policy

Last updated: September 14, 2026

What this application is

AnyFix Books is a private integration built and operated by AnyFix Systems LLC ("AnyFix", "we", "us") for its own internal bookkeeping. It connects to a single QuickBooks Online company file — the one belonging to AnyFix Systems LLC — and is not offered, sold, or made available to any other person or organization. There are no user accounts, no sign-up, and no customers of this application other than AnyFix Systems LLC itself.

What data the application accesses

When connected, the application can read and write accounting records in that one QuickBooks Online company file, using the QuickBooks Online Accounting API under the com.intuit.quickbooks.accounting scope. In practice this means:

  • Company information
  • Chart of accounts
  • Vendors
  • Expenses and journal entries
  • Standard financial reports (Profit and Loss, Balance Sheet, Transaction List, General Ledger)

The application creates and updates records. It does not delete QuickBooks records.

The application does not access bank credentials, payment card numbers, payroll records, or customer payment instruments.

How credentials are stored

OAuth 2.0 credentials — the client ID, client secret, and refresh token — are stored in the macOS Keychain on a computer controlled by AnyFix Systems LLC. They are not written to any file, not stored on any server, and not transmitted anywhere other than to Intuit's own authentication endpoints. There is no hosted backend, no database, and no cloud storage associated with this application.

Access tokens are held in memory only, for the life of a running process.

Use of artificial intelligence, and the resulting data transfer

This is the most important disclosure in this document, so it is stated plainly.

AnyFix Books is a Model Context Protocol (MCP) server. Its operations are invoked by an AI assistant — Claude, provided by Anthropic — acting on instructions from an authorized person at AnyFix Systems LLC. As a direct consequence, accounting data retrieved from QuickBooks Online is transmitted to Anthropic's API in order to fulfill those instructions, and instructions containing accounting details are sent there as well.

Anthropic's handling of that data is governed by Anthropic's own terms and privacy policy. AnyFix Systems LLC does not use QuickBooks data to train any model.

No QuickBooks data is transmitted to any other third party. It is not sold, rented, licensed, or shared for advertising, analytics, or any other purpose.

Error logs

Failed API calls are recorded to a local file on the operator's computer (~/.anyfix-books/qbo-errors.log). Each entry contains the operation attempted, the HTTP status returned, the intuit_tid identifier from Intuit's response, and the error body Intuit returned. This exists so that a problem can be reported to Intuit support with enough detail to trace it.

No credential — client ID, client secret, refresh token, or access token — is written to this log. The log rotates and is capped at five files of one megabyte each, so it does not grow without limit. Successful calls write nothing.

Data retention

QuickBooks records themselves live in QuickBooks Online and are retained under Intuit's terms, not ours. The credentials described above are retained until the connection is revoked. Error log entries are retained until rotated out by the size cap described above.

Revoking access

Access can be revoked at any time from the QuickBooks Online account, under Settings → Apps, or through Intuit's OAuth token revocation endpoint. Revocation immediately ends the application's ability to read or write anything.

Children's data

This application is not directed to children and processes no data about children.

Changes to this policy

If the application's behavior changes in a way that affects what is described here, this page will be updated and the "last updated" date above changed.
